# Logi-web

Configurador web minimalista para el ratón Logitech G PRO X SUPERLIGHT 2. Habla directamente con el ratón desde el navegador.

## Dispositivo

**Ratón**:
El Logitech G PRO X SUPERLIGHT 2 que se configura; se identifica a sí mismo como "PRO X 2".
_Avoid_: Dispositivo, periférico, mouse

**Receptor**:
El dongle Lightspeed USB a través del cual el Ratón se conecta de forma inalámbrica.
_Avoid_: Dongle, adaptador

**Conexión**:
La vía activa por la que la app habla con el Ratón: a través del Receptor o por cable USB.
_Avoid_: Enlace, sesión

## Configuración

**Perfil onboard**:
Conjunto de ajustes guardado en la memoria interna del Ratón, que persiste sin software. El Ratón tiene cinco; uno es el Perfil activo.
_Avoid_: Perfil (a secas), preset, configuración

**Perfil activo**:
El Perfil onboard que el Ratón está usando ahora mismo.

**Etapa DPI**:
Uno de los valores de DPI de un Perfil onboard entre los que el Ratón alterna; una de ellas es la Etapa por defecto.
_Avoid_: Nivel DPI, paso DPI, preset DPI

**Etapa por defecto**:
La Etapa DPI con la que arranca el Perfil onboard.

**Polling rate**:
Frecuencia (en Hz) con la que el Ratón informa su posición. Las opciones disponibles las dicta el Ratón según la Conexión.
_Avoid_: Report rate, frecuencia de sondeo, tasa de refresco

## Cambios

**Aplicar en vivo**:
Enviar un ajuste al Ratón para que tenga efecto inmediato pero temporal; se pierde al apagarlo.
_Avoid_: Previsualizar, probar

**Guardar**:
Escribir los ajustes en el Perfil activo para que persistan.
_Avoid_: Aplicar, sincronizar, flashear

**Copia de seguridad**:
Volcado completo de la memoria de Perfiles onboard del Ratón a un archivo, tomado antes de la primera escritura y restaurable.
_Avoid_: Backup, exportación, snapshot
